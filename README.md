# Tourism Data Analysis and Travel Trend Visualization

## Project objective
Analyze tourist visits, destinations, monthly travel trends, visitor origin/type, average stay, and tourism revenue using Python and charts.

## Important data note
`dataset/tourism_data.csv` contains **fictional sample data created for learning**. It is not official or real tourism statistics. Replace it with a credible dataset before reporting factual conclusions.

## Tools
- Google Colab / Jupyter Notebook
- Python
- Pandas
- Matplotlib

## Folder structure
- `dataset/tourism_data.csv` — sample data
- `notebook/tourism_analysis.ipynb` — starter analysis notebook
- `visualizations/` — save exported charts here
- `report/` — project report and findings

## How to run in Google Colab
1. Open https://colab.research.google.com/
2. Choose **New notebook**.
3. Upload `tourism_data.csv` from the `dataset` folder to the Colab session using the Files panel.
4. Open `notebook/tourism_analysis.ipynb` locally, copy its cells into Colab, or upload the `.ipynb` file to Colab.
5. If you upload the notebook file, upload `tourism_data.csv` to the Colab session as well. The starter notebook expects `/content/tourism_data.csv`.
6. Run cells from top to bottom.
7. Download the generated chart images and place them in `visualizations/`.

## Questions this project explores
1. Which destination has the highest recorded visitor count?
2. How do visits change month by month?
3. Which destination has the highest recorded revenue?
4. What is the domestic/international visitor mix?
5. What is the average length of stay?
